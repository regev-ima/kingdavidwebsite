שינוי שמות תמונות מוצרים

הכלי הזה לוקח תיקייה עם תיקיות-משנה (תיקייה לכל מוצר), משנה את שמות התיקיות והקבצים ל‑ASCII בלבד, ומוריד ZIP חדש שמוכן להעלאה ל‑Supabase Storage.

  1. בחר את התיקייה הראשית עם תיקיות המוצרים (זאת שחילצת מ‑Drive).
  2. הכלי ייצור ZIP חדש בשם product-images-renamed.zip.
  3. פתח את ה‑ZIP, ועלה את כל התיקיות לתוך bucket ה‑product-images ב‑Supabase Dashboard.
  4. שלח לי גם את mapping.json שיירד יחד עם ה‑ZIP — אני צריך אותו כדי לקשר תיקייה למוצר.
